Teaching Claude to Diagnose Before It Writes

A one time install that changes how Claude approaches any piece of persuasive writing, so it thinks about the reader first instead of reaching straight for hype.

  • ToolClaude
  • StepsFive
  • IncludesSkill file to upload

What this actually does

Most AI written marketing copy sounds like AI written marketing copy. It is generic and could belong to any agent in any market. The fix is not a cleverer prompt, it is teaching Claude to think about who is actually reading before it writes a single word. That is what a Claude skill does. You upload a small file once, and Claude keeps it on hand, pulling it into any relevant conversation automatically from then on.

This particular skill runs a five step process before Claude writes ad copy, emails, listing descriptions, or captions. It figures out where the reader's head is at, picks a structure that fits the situation instead of forcing a template onto everything, chooses the one psychological angle that matches what is actually holding the reader back, checks the draft against the thinking of eleven well known copywriters and behavioral researchers, and finally audits the result for the habits that make copy sound like an ad instead of a person.

What you will need

Before you start
  • A Claude account. Free, Pro, or Max all work
  • Code execution and file creation turned on in your Claude settings, since skills run inside that capability
  • Two or three minutes to complete the install

How to use it

Setup takes two or three minutes. Five steps.

  1. Download the skill file

    Download the zip below and save it somewhere you can find it. Don't unzip it — Claude expects the .zip file exactly as-is. This one is what we call a super skill — most skills are a single document, but this one packs six reference files alongside the core instructions: persuasion frameworks, psychological levers, the 11-mind panel, pre-framing and objection-handling playbooks, failure modes, and worked examples. Claude pulls them in automatically when a task needs the extra depth.

    marketing-psychology.skill

    The persuasion skill and its six reference files, packaged for upload into Claude.

    Download

  2. Turn on Code Execution

    In Claude, go to Settings > Capabilities and make sure Code execution and file creation is toggled on. Skills run inside this capability — nothing works without it. If it's already on, you're done with this step.

  3. Open your Skills page

    Go to Customize > Skills. This is where every skill you install lives — Anthropic's built-in skills plus any custom ones you upload.

  4. Upload the skill

    Click the "+" button, choose Create skill, then select Upload a skill. Pick the zip from Step 1. Within a few seconds it appears in your skills list as marketing-psychology — that's the one.

  5. Confirm it's on and put it to work

    Skills you upload are usually toggled on by default — but glance at the switch next to it just in case. Once it's on, you're live. There's nothing to invoke and nothing to remember — start any copy task and Claude detects persuasion work and loads the skill on its own. Try something like: "Write an email to my past clients about the new listing at [ADDRESS] — three bedrooms, walkable to downtown, listed at [PRICE]." And if you ever want to guarantee it fires, say so directly: "Use the marketing psychology skill."
