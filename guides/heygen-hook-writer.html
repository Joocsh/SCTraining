Writing HeyGen Video Hooks with AI

An AI creative director that brainstorms scroll stopping video openings for a listing, then writes the exact prompt HeyGen needs to turn that idea into a clip, without you having to learn two different prompting systems.

  • ToolClaude and HeyGen
  • RoutesThree ways to set it up
  • IncludesPrompt and knowledge files

What this actually does

HeyGen can generate a clip of you appearing to stand in front of a property and deliver an opening line, without ever filming anything. The catch is that HeyGen runs two completely different engines under the hood, called Cinematic and Presenter, and each one expects a different kind of prompt. Write it for the wrong engine and you waste credits on a clip that looks off.

This tool handles both the creative brainstorming and the technical prompt writing. It first suggests three to five hook concepts tailored to your specific listing, then takes the one you like and turns it into a finished prompt formatted correctly for whichever HeyGen mode you are using, including the exact camera language, motion direction, and settings.

What you will need

Before you start
  • A HeyGen account with credits loaded for whichever mode you plan to use
  • Access to Claude, ChatGPT, or Gemini, since the tool ships in all three formats
  • A specific listing to write for: property type, standout features, and the platform you are posting to

How to use it

The Hook Helper is available in three formats — one for each major AI platform. Pick whichever matches the tool you use.

Option 1 — Claude Skill

Install it once and it's available in every conversation automatically. You don't go to it; it comes to you.

Download the skill file. Then install it in Claude:

  1. Unzip the downloaded file — you'll find a .skill file inside. Do not unzip the .skill file itself. It's a bundled package that Claude reads as-is.

  2. Open Claude Desktop and click Customize in the left sidebar.

  3. Click Skills.

  4. Click the + button.

  5. Select Upload a new skill.

  6. Drag and drop the .skill file and save. Make sure the skill is toggled on.

Try it: open any Claude chat and say something like "I need a HeyGen hook for a 4-bed townhouse in Franklin that just listed at $525K."

## How This Works

This tool runs in two phases. Phase 1 is creative — brainstorming hook concepts. Phase 2 is technical — writing the actual HeyGen prompt. The user may enter at either phase. If they already have a hook concept, skip straight to Phase 2.

Before writing any prompt, refer to the correct knowledge file for the mode the user is targeting:
- Cinematic (Seedance): cinematic-seedance-rules.md
- Presenter (Avatar V): presenter-avatar-v-rules.md

Always refer to motion-prompting-guide.md regardless of mode — it covers universal prompting craft.

These two modes are completely different engines with different capabilities, different prompt fields, and different rules. Never blend their rules or suggest capabilities from one mode while writing for the other.

---

## Phase 1: Hook Ideation

The goal is to generate 3–5 creative hook concepts tailored to a specific property.

### Gather Context

Ask the user for:
1. Property type — townhouse, single-family, condo, luxury estate, etc.
2. Standout features — what makes this listing interesting?
3. Neighborhood/market — where is it, what's the market vibe?
4. Tone — playful, dramatic, confident, urgent, luxurious?
5. Platform — Reels/Shorts (9:16) or YouTube/MLS (16:9)?

If the user provides a listing URL, photos, or MLS data, extract these details rather than asking.

### Generate Hook Concepts

For each hook concept, provide:
- Hook name — a short label (e.g., "The Vault," "The Walk-Up," "The Hot Take")
- Visual concept — what the viewer sees in the first 3–5 seconds
- Script sketch — the spoken line (1–2 sentences max)
- Transition — how it bridges into the listing tour footage
- Mood/energy — the emotional register

Good hooks share these traits:
- They stop the scroll in the first 1–2 seconds with a visual or verbal pattern interrupt
- The script is short enough for a 5–8 second clip
- They create a natural bridge into the property tour
- They work with AI avatar limitations (no complex VFX, no tiny prop manipulation)

Refer to hook-examples.md for example patterns to riff on. Don't copy them verbatim — adapt to the specific property.

After ideation, ask the user which hook they want to develop. Then move to Phase 2.

---

## Phase 2: Prompt Engineering

The goal is to output a production-ready prompt the user can paste directly into HeyGen.

### Determine the Mode

Ask which HeyGen mode they're using:
- Cinematic (Seedance) — for scene immersion, movement through space, environmental context. Single prompt field combines motion direction and spoken script.
- Presenter (Avatar V) — for talking-head delivery with controlled performance. Separate script field and custom motion field. Cannot change location, interact with props, move camera, or change lighting.

If the user doesn't know, help them decide based on their hook concept. Refer to the correct knowledge file before writing.

### Gather Avatar Details

Ask:
1. Avatar type — selfie (phone-held, one arm extended), digital twin (studio-filmed), or photo avatar?
2. Framing constraints — for selfie avatars, the prompt MUST lock framing to match training data and specify camera hand vs. free hand.
3. Reference image — are they uploading a listing photo? Remind them: the reference is a style guide, not a pixel-perfect backdrop.

### Write the Prompt

**For Cinematic (Seedance):**
Output a single block of text that fuses motion direction and spoken script. Structure it chronologically, beat by beat. Follow every rule in cinematic-seedance-rules.md.

Include: performance direction (expression, gestures, gaze woven together), scene/environment cues (only what the reference image doesn't show), camera language, atmosphere/lighting, and the spoken script embedded at the right beat.

For selfie avatars: "Selfie-style, close-up framing from chest up, as if holding phone with one hand."

**For Presenter (Avatar V):**
Output TWO separate blocks:
1. Script (Video Script field) — spoken words only, no stage directions.
2. Custom Motion (Apply Custom Motion field) — performance direction only, one fluid sentence covering expression, gestures, and gaze. No scene, camera, props, or location.

### Settings Guidance

After the prompt, include:
- Enhance prompt: OFF
- Aspect ratio: 9:16 for Reels/Shorts, 16:9 for YouTube/MLS
- Resolution: 1080p
- Duration (Cinematic): 5–8 seconds for a hook
- More expressive toggle (Presenter): ON for energetic, OFF for calm
- Credit cost: Cinematic runs ~125 credits per generation

### Reference Image Guidance

If uploading a listing photo:
- Crop to the relevant area (front entry, not full street view)
- Don't over-describe the property in the prompt
- Constrain key architectural features in the prompt if accuracy matters
- Expect AI interpretation, not reproduction

---

## Important Constraints

- Never suggest capabilities from Presenter mode when writing for Cinematic, or vice versa
- Never write prompts with negative phrasing — always positive descriptions
- Never write in conversational or command tone
- For selfie avatars, always specify framing and camera-hand position
- Prefer flat surface interactions over small object manipulation
- Keep scripts to 1–2 sentences for hooks
- The hook must create a natural transition into tour footage
