Turning a CRM Export into a Call List

A single prompt that reads a full lead export, flags where the pipeline is actually stuck, and hands back the specific leads worth calling today, with a script for each one.

  • ToolClaude
  • StepsSeven
  • IncludesOne analysis prompt

What this actually does

A large CRM database is overwhelming to look at cold. Most agents end up either ignoring it or calling whoever happens to come to mind, not whoever the data actually says is closest to converting. This prompt fixes that by reading an entire export at once, cross referencing activity, tags, and notes on its own, and producing a short report with three parts: a scorecard of the pipeline's health, a ranked list of the leads most likely to convert soon, and a ready to use script for each one of those leads based on their real history.

It takes about five minutes to run and works with any CRM's export, not just one specific platform.

What you will need

Before you start
  • A full CSV export of one agent's leads from your CRM, with every column included and nothing pre filtered
  • Access to Claude with Cowork, since the file needs to be read with code rather than eyeballed
  • A few minutes to answer two or three quick questions before the report runs

How to use it

  1. Log into your CRM

    Open Sierra Interactive, Follow Up Boss, kvCORE, or whichever platform the agent uses. You'll be exporting their lead list in the next step.

  2. Pull a full CSV export of the agent's leads

    Include every column your CRM gives you — status, source, last activity, history, visits, properties viewed, tags, notes, dialer activity, all of it. Don't clean or trim anything. One agent per export; mixing two agents' data into one file muddies the results.

  3. Open a fresh Claude Cowork chat

    Start a new Cowork task — not an existing conversation. One agent per chat for clean results.

  4. Drag the CSV file into the chat

    Drop the export file directly into the Cowork conversation. Claude will read the full file when you send the prompt.

  5. Paste this prompt

    Copy the full prompt below and paste it into the chat. If your CRM isn't Sierra Interactive, swap the platform name in the first paragraph and adjust the Part 1 metrics to match what your system exports. The structure — scorecard, hottest leads, scripts — works the same way regardless of platform.

    Agent Roadblock Report prompt — paste this into Cowork 
    You are my real estate operations analyst. I just uploaded a CSV. It is a full lead export from Sierra Interactive for one of my agents. I have not cleaned or filtered it. Read every row. Cross-reference activity, history, visits, tags, status, and notes on your own.

Produce an Agent Roadblock Report. Use plain English, short sentences, hyphens instead of em-dashes, and a confident, no-fluff tone. Pull every number, name, date, and address straight from the CSV - do not invent anything. If a field is missing, mark it as Unknown rather than skipping it.

The report should be organized into three parts. You can adjust formatting (tables, bullets, paragraphs) to whatever reads cleanest, but make sure all of the following information is captured and clearly presented.

PART 1 - PERFORMANCE SCORECARD
A snapshot of the agent's activity inside Sierra. Include the metrics that are useful for spotting dormancy, missed follow-up, and overall pipeline health. At minimum cover: total database size, dormancy rate (leads with no activity in 90+ days), cold or lost active leads, year-to-date closed transactions and volume, recent session activity, last login, new leads in the last several weeks, leads not yet viewed, time to first email, time to first call, dialer activity, outbound call/text/email counts in the last several weeks, and tasks sitting with no action. Flag each metric as OK, Warning, or Critical based on whether it is healthy, slipping, or genuinely broken. Use your judgment on thresholds based on what looks normal vs. neglected in the data.

PART 2 - HOTTEST LEADS RIGHT NOW
The top handful of leads (5 is a good default) most likely to convert in the near term. For each one, capture name, status, days since last touch, and source. Pick based on a combination of recent engagement signals (visits, properties viewed, replies, lead score, recent activity) and viable status. Rank them in priority order.

PART 3 - PERSONALIZED FOLLOW-UP SCRIPTS
For each of the leads listed in Part 2, give the agent everything they need to make the call. Capture:
Lead name, type (buyer, seller, nurture), and source.
- Phone, email, and location.
- Price band, visit count, and properties viewed.
- Key Intel: a short paragraph pulling specific facts from the CSV - what they clicked, what the agent has already done, dates of last touches, referral source, lead score, anything that explains why this lead is hot or stuck. Use real dates and real properties from the data.
- A recommended script or approach the agent can read off their phone. Reference the last specific interaction. Sound human, not corporate. If the lead has been called multiple times with no callback, pivot to text or email and write the actual message to send.

ASK ME FIRST
Before producing the report, ask:
1. Agent's first and last name.
2. Their role (listing, buyer, dual).
3. Any context I want factored in (new agent, slump, just back from leave, personal stuff, etc.).

Then read the CSV and produce the report.

  6. Answer the clarifying questions about the agent

    Before producing the report, Claude asks three questions: the agent's full name, their role (listing, buyer, or dual), and any context worth factoring in — new agent, slump, just back from leave. Answer honestly. The tone of the scripts depends on it.

  7. Claude reads the entire export and produces your report

    The finished report has three parts. Part 1 is the Performance Scorecard — each metric flagged OK, Warning, or Critical. Part 2 is the five hottest leads ranked by conversion likelihood. Part 3 is a personalized follow-up script for each of those five leads, referencing their real CRM history. If a lead has been called multiple times with no callback, the script pivots to a text or email and writes the actual message to send.

Using this with a different CRM

This prompt is built for Sierra Interactive, but works with any CRM. Swap "Sierra Interactive" for your platform name in the first paragraph and adjust the metrics in Part 1 to match what your system exports. The structure — scorecard, hottest leads, scripts — works the same way.

Tips

  • Run one agent per chat for clean results. Don't mix two agents' data into one report
  • Don't pre-filter the data — let Claude spot the patterns in the full, unedited export
  • Use the OK / Warning / Critical flags to prioritize coaching conversations, rather than guessing at what the real problem is
  • The personalized scripts reference real interactions from the CRM, so they sound natural instead of generic — that's only possible if the data going in is complete
