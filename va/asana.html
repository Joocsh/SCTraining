Get started

Introduction to Asana

E-mails, deadlines, meetings, trying to handle it all at once can lead to disaster. This module introduces the tool that keeps it from happening.

1

Think of Asana like a GPS

Think of Asana like the GPS system on a boat. It'll help you navigate, and stay afloat, through a messy current of tasks, meetings, deadlines, and everything in between.

2

What is Asana?

Asana is a task management tool. It's designed to help you and your team organize, track, and manage the work that needs to be done. You can create projects, assign tasks, set deadlines, and monitor progress, all from one place.

Why it mattersAsana helps teams collaborate efficiently by providing visibility into who's doing what, and by when. Nothing falls through the cracks because everything lives in one shared system.
3

What Asana organizes for you

Tasks

The individual pieces of work that need to get done, the building blocks of everything in Asana.

Deadlines

Due dates keep work moving and make sure nothing is left open-ended.

Projects

Groups of related tasks, organized so a team can see the full picture of an initiative.

Collaboration

Teams, comments, and notifications keep everyone aligned without extra meetings or emails.

Work with tasks

Creating a Task

Tasks are the building blocks of Asana. This is where day-to-day work actually gets captured and tracked.

1

Step by step

  1. 1

    Click on Create

    The red "Create" button sits in the top-left of your Asana workspace.

  2. 2

    Click on Task

    Choose "Task" from the dropdown menu that appears.

  3. 3

    Type the name of your task

    Give the task a name in the "New task" window.

  4. 4

    Type the description

    Add detail in the description field so anyone opening the task understands what's needed.

  5. 5

    Click on Create task

    This saves the task. You can also add attachments, set a due date, and assign it to a teammate right from this window.

Why clear titles matter

A clear, concise task title lets anyone scanning a list understand the task at a glance, no need to open it just to find out what it is.

Why descriptions matter

A detailed description means the task can be picked up by anyone, without a follow-up meeting or message to explain what's needed.

Scenario 1 · Creating a task

Your manager asks you to prepare a weekly performance report by Friday.

Here's how you'd capture that in Asana:

Task namePrepare Weekly Performance Report
DescriptionCompile this week's performance results, verify the information, attach the final report, and notify the manager when completed.
Due dateFriday
Why this task works
  • The title is clear, anyone glancing at it instantly knows what the task is.
  • The description spells out exactly what "done" looks like: compile, verify, attach, notify.
  • The due date creates accountability and prevents the task from slipping.

Managing Task Details

Once a task exists, subtasks, tags, and attachments help you break it down, organize it, and give it everything it needs to be actionable.

1

Creating a subtask

  1. 1

    Select a task

    Open the task, then scroll down to the bottom of the task panel.

  2. 2

    Add subtask

    Click "+ Add subtask" and type the name of the smaller piece of work.

Scenario 2 · Subtasks

Main task: Prepare Monthly Client Report

Broken into subtasks:

  • Collect performance data
  • Review information
  • Create report
  • Quality check
  • Send for manager review
Why subtasks help
Subtasks break a large assignment into smaller, trackable pieces. Instead of one task sitting untouched until it's "done," you can see exactly which step is in progress, which makes bigger projects far less overwhelming and easier to monitor.
2

Adding tags

  1. 1

    Select a task

    Open the task you want to tag.

  2. 2

    Select Add Tags

    Open the "..." menu and choose "Add tags", then pick or create the relevant tag.

Tags are important in Asana because they help you add context, improve organization, and find tasks more easily, especially across different projects.

Scenario 3 · Tags

An employee manages tasks for several departments.

They tag each task with the relevant area:

  • Marketing
  • Finance
  • Operations
  • Urgent
Why this helps
With tags applied consistently, this employee can filter their task list by "Finance" during budget week, or pull up every "Urgent" item across every project in seconds, without digging through each individual project.
3

Adding attachments

  1. 1

    Select a task

    Open the task that needs a supporting file.

  2. 2

    Click on the upload button

    Choose to upload from your computer, or link from Dropbox, Google Drive, Box, or OneDrive. Then select the file you want to upload.

Scenario 4 · Attachments

An employee is responsible for reviewing a document.

Instead of emailing the file back and forth, they attach the relevant PDF, spreadsheet, screenshot, or reference document directly to the Asana task, so the file, the discussion, and the deadline all live in one place.

When to use each featureUse subtasks to break down multi-step work. Use tags to categorize work by department, priority, or type. Use attachments to keep supporting files right where the work is happening.

Projects and teams

Working on a Project

The endgame of any task you work on is to accomplish something. Think of it as baby steps, projects let teams structure work in a way that is clear and actionable.

1

What is a project?

A project is a group of related tasks. Where a task is one piece of work, a project is the container that keeps every task related to a bigger goal organized in one place, so anyone can see the full picture of an initiative.

2

Creating a project

  1. 1

    Click on Create

    Open the same Create menu used for tasks.

  2. 2

    Click on Project

    Choose "Project" from the dropdown.

  3. 3

    Select the option that best suits what you need

    Choose "Blank project" to start from scratch, "Use a template" to start from a library template, or "Import project" to bring in data from files or another tool.

  4. 4

    Type the name of the project

    Name it something specific and recognizable to your team.

  5. 5

    Click on Continue

  6. 6

    Choose the ways you'd like to monitor overall progress

    Asana recommends starting views like Overview, List, Board, Timeline, and Dashboard.

  7. 7

    Check any extra views you'd like

    Add optional views such as Calendar or Workload if they'll help your team.

  8. 8

    Click on Create project

    Your project is created and ready for tasks.

You've now created your projectYou can now create tasks, assign tasks, and set due dates inside it, exactly as covered in Modules 3 and 4.

Scenario 5 · Project management

Project: New Employee Onboarding

  • Create employee account
  • Prepare training schedule
  • Assign trainer
  • Complete system training
  • Complete process training
  • Final evaluation
Why a project keeps this organized
Every task related to bringing on a new hire lives in one place. HR, the hiring manager, and the trainer can all see the same list, know what's done, what's in progress, and who owns each step, instead of tracking onboarding across scattered emails.

Teams

Depending on the size of the project or task you're working on, you'll be working with multiple people. That's where teams come in.

1

What is a team?

Teams can be defined as multiple people working on related projects. They help organize work by department, project type, or other criteria, so the right people always have access to the right projects.

2

Creating a team

  1. 1

    Click on Create

  2. 2

    Click on Team

    Choose "Team" from the Create dropdown.

  3. 3

    Type the name of your team

  4. 4

    Add team members by name or email

    Start typing to search your workspace, or enter an email address directly.

  5. 5

    Add your members

    Select each person from the dropdown suggestions.

  6. 6

    Click on Create new team

    Your team is now set up and ready to be attached to projects.

Scenario 6 · Team collaboration

Team: Operations Team

Members:

  • Operations Manager
  • Team Leader
  • Associate
  • Trainer
Why access matters
Making sure the correct employees have access to the appropriate project means everyone doing the work can see it, comment on it, and stay updated, while people outside the team aren't cluttered with projects that don't concern them.

Assignments and Notifications

Have you ever heard "communication is key"? For a project to be successful, everybody needs to be in the loop, and Asana gives you the tools to make it happen.

1

Notifications

Asana sends notifications via email and within the app. Notification settings can be modified to avoid unnecessary clutter in your inbox. You should check this, preferably daily, so you never miss an important update.

2

Assigning a task to a team member

  1. 1

    Click on the task you'd like to assign

  2. 2

    Click on assignee

    Select the "No assignee" field on the task.

  3. 3

    Select the person to whom the task will be assigned

    Search by name or email and choose the correct team member from the list.

  4. 4

    Click on Due date

  5. 5

    Select a due date

    Pick the date from the calendar.

  6. 6

    Close

    Your task is now assigned, dated, and ready to go.

Best practices

Asana Best Practices

Following these best practices will help you and your team stay organized, productive, and aligned with your goals.

Task Management Tips

  • Keep task titles clear and concise.
  • Use task descriptions to provide detailed instructions.
  • Add tags and custom fields for better task categorization.

Project Organization Strategies

  • Use project templates for recurring workflows.
  • Break large projects into smaller sections for better tracking.
  • Set milestones to track progress toward key goals.

Team Collaboration Techniques

  • Encourage regular updates in task comments.
  • Utilize team meetings to review Asana boards.
  • Ensure all stakeholders have access to relevant projects.
