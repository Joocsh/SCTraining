2. Agency Relationships Defined

When you enter into a discussion with a real estate agent regarding a real estate transaction, you should understand what type of agency relationship or representation you have with the agent in that transaction. California Civil Code Sections 2079.13 through 2079.24 govern agency relationships in residential real property transactions.

Seller's Agent

A Seller's Agent, under a listing agreement with the Seller, acts as the agent for the Seller only. The Seller's Agent has a fiduciary duty of utmost care, integrity, honesty, and loyalty in dealings with the Seller. The agent may not disclose to the Buyer confidential information about the Seller's motivations, urgency, or willingness to accept less than the listing price without written consent from the Seller.

Buyer's Agent

A Buyer's Agent acts as the agent for the Buyer only. The Buyer's Agent has a fiduciary duty of utmost care, integrity, honesty, and loyalty in dealings with the Buyer. The agent may not disclose to the Seller confidential information about the Buyer's motivations, urgency, or willingness to pay more than the offering price without written consent from the Buyer.

Dual Agent

A Dual Agent represents both the Seller and the Buyer in the same transaction. Dual agency may occur when both the listing agent and the buyer's agent are licensed under the same brokerage. In a dual agency situation, the agent owes a fiduciary duty to both parties but cannot disclose confidential information from one party to the other without consent. Dual agency requires the informed written consent of both the Seller and the Buyer.
