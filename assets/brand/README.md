# assets/brand/

Entrega original del diseñador de SkillCloud. Se conserva la numeración original de las
carpetas porque refleja el orden en que fue entregada.

| Carpeta                       | Contenido                                              |
| ----------------------------- | ------------------------------------------------------ |
| `0 - BRAND/`                  | Manual de marca y fuentes oficiales (Visby CF, Sandra)  |
| `1 - LOGO/`                   | Logos, incluidos los editables `.ai`                    |
| `2 - WEBSITE/`                | Fotos, iconos, favicon y variantes de logo para web     |
| `3 - SOCIAL MEDIA PROFILE/`   | Banners de Facebook, LinkedIn y YouTube                 |
| `4 - BANNER EMAIL/`           | Banner para firmas de correo                            |
| `5 - REPORT SLIDE TEMPLATE/`  | Plantilla de presentaciones                             |

## Esto no lo usa el sitio

Ninguna página referencia esta carpeta. Las imágenes que el sitio sí carga están en
`assets/img/`. Aquí viven los archivos maestros y editables (`.ai`, `.psd`, PNG a tamaño
completo) para trabajo de diseño.

Es también la razón de que el repo pese unos 440 MB: son unos 340 MB de esta carpeta. Si
solo vas a trabajar en el sitio, no necesitas nada de aquí.
