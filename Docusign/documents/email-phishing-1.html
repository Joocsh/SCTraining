Five tells, in the order a coordinator should find them. 1. The sending domain is docus1gn-securesign.net — the letter i replaced by the digit 1, and a suffix that no Docusign domain uses. 2. SPF softfails and DKIM fails outright; a real Docusign notification passes both for docusign.net. 3. There is no Alternate Signing Method block and no security code, because there is no envelope behind this message. That absence is the cleanest single tell in the email. 4. It asks for a corporate email password. Docusign never does; signing is authenticated by the link, an access code, or ID verification. 5. A one-hour countdown with legal threats. Urgency is the payload — it exists to stop you checking the first four.
