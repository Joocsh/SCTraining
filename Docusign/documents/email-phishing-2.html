Harder than the first one, and closer to what actually lands in a coordinator's inbox. The layout is right, the logo is right, the blocks are all present, and the visible From address really does read dse@docusign.net. Four things still give it away. 1. The Return-Path is cloudserver-node88.xyz, not a Docusign host — the display name is cosmetic, the envelope sender is not. 2. SPF fails for docusign.net and there is no DKIM signature at all, which is what spoofing the From address costs you. 3. The button points at a bare IP address instead of a *.docusign.net host. Read link destinations, never link text. 4. The security code is a made-up string. Type it into docusign.com yourself and no envelope comes back — which is the check the Alternate Signing Method block exists to let you make.

Neither Lucas Adminton nor Best Closing Inc. appears anywhere in this account's address book. Verify envelopes in Agreements, not in your mail client.
