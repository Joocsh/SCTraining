# Fotogramas de referencia — AppFolio "Full Layout and Navigation"

32 pantallas únicas extraídas de un tutorial en video de AppFolio Property Manager.
Cuenta de demostración `demobaumgardner.appfolio.com`. Resolución original 1920×1080.

**Método.** Video de 4:26 muestreado a 1 fotograma cada 2 segundos (133 en total),
indexado con hojas de contacto, y de ahí seleccionadas las 32 pantallas distintas.
Detección automática de escena no sirvió: en un screencast el cursor moviéndose basta
para marcar cada fotograma como distinto.

> ### ⚠️ Antigüedad — léelo antes de usar estas imágenes
>
> Los datos en pantalla llevan fechas de **2016 a 2019** (`12/27/2016`, `11/20/2018`,
> `01/01/2019`). Este tutorial es de alrededor de **2018–2019**, no del presente.
>
> Sirve como referencia de **arquitectura de navegación** — qué secciones existen, cómo
> se anidan, qué columnas tiene cada tabla. **No sirve como referencia visual actual.**
> AppFolio ha rediseñado su interfaz desde entonces. Antes de copiar un color, un radio
> de borde o una tipografía de aquí, verifica contra el producto vivo.
