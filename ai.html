The Foundation Start here

What Is AI and How Does It Work?

Artificial intelligence, in the context of the tools you'll use every day, means software that understands language and generates responses. You type something in plain English, the model reads it, and writes back. That is the complete interaction: no code required, no special syntax, no buttons to configure.

The specific type of AI behind these tools is called a Large Language Model, or LLM. It was trained on an enormous body of text (books, websites, articles, code) and learned to predict what words follow what other words. From that training emerges something that can summarize a contract, draft a client email, debug code, and explain a zoning rule, all in the same conversation.

How a language model processes your request
Key distinction

Automation follows fixed rules. An auto-reply, a form trigger, a calendar reminder: these do the same thing every time. AI reads your input and generates a response that fits your specific situation, every time. The two tools complement each other; they are not the same thing.

The one rule that determines output quality

The quality of what you get back depends almost entirely on what you put in. A vague question gets a vague answer. A specific, well-structured prompt with context, a clear goal, and the relevant details gets a response that is actually useful. Every technique in this training comes back to that principle.

You do not need to master these tools before you start. You learn them by using them. The goal of this module is to give you a clear mental model of what each tool is, where it fits, and how to get results from it on day one.

Module 01 Claude by Anthropic
Anthropic · Constitutional AI

Claude

Made by Anthropic — founded 2021, San Francisco

A writing and thinking partner built for nuance, long documents, and following complex instructions. The primary AI tool for SkillCloud work.

What it is

Claude was built by Anthropic, a company founded in 2021 by researchers who left OpenAI with a specific focus: making AI that is genuinely safe and useful rather than simply impressive. Their approach, called Constitutional AI, means Claude was trained with a clear set of principles: not just to be helpful, but to be honest about what it does not know and to avoid harm.

In practice, this means Claude is excellent at following complex, multi-part instructions without drifting from your request. It handles very long documents without losing track of earlier details. Its writing tends to feel more natural and less templated than other models. And it is careful: if it is uncertain about something, it says so rather than inventing a confident-sounding answer.

What Claude does best

Long document analysis

Upload a full contract, listing agreement, or CRM export. Claude reads the whole thing and finds what you ask for.

Nuanced writing

Emails, listing descriptions, SOPs, client scripts: Claude writes in a natural voice that does not sound like a template.

Complex instructions

Give Claude a 10-step brief and it follows all 10 steps without losing track halfway through.

Honest uncertainty

When Claude doesn't know something or can't verify a fact, it says so, rather than inventing a plausible-sounding answer.

Structured output

Tables, checklists, bulleted lists, formatted reports: Claude produces clean structure you can copy directly into a doc.

200K token context

Claude holds roughly 150,000 words in a single conversation, enough for a full client file, multiple documents, and your instructions.

Claude's tools beyond the chat window

Claude.ai is the chat window most people picture, but that is one surface of a larger product. Anthropic ships several tools built on the same underlying model, each suited to a different kind of work.

Projects Organize by client or task

A Project keeps one client, campaign, or workflow together in its own space: custom instructions, uploaded reference files, and a running history that Claude can pull from automatically. Set the context once inside the Project, and every new conversation started there already has it loaded, instead of you re-explaining the same background every time.

Artifacts Live preview canvas

When Claude produces something meant to be viewed rather than read (a webpage, a diagram, a working prototype, a formatted document) it opens in a separate live preview pane called an Artifact. You keep iterating on it inside the same conversation and can share the finished result as a link.

Skills Reusable playbooks

A Skill is a packaged, reusable set of instructions that teaches Claude exactly how your team wants a specific task done: the steps to follow, the format to use, the checks to run before calling it finished. Once a Skill exists, anyone on the team gets the same quality result by invoking it, instead of everyone writing their own prompt from scratch.

Cowork Autonomous execution

Cowork is Claude working as an autonomous operator instead of a chat partner. Hand it a folder of reference files and a task, and it works through a defined workflow end to end: reading files, producing drafts, checking its own output against a checklist, before handing back a finished deliverable. It is built for repeatable, multi-step business workflows, like the campaign engines referenced elsewhere in this training.

Claude Code Engineering agent

Claude Code is Claude running inside a command line or code editor as an engineering agent. It reads a codebase, writes and edits files directly, runs commands, and can manage version control, all inside your own development environment. This is the kind of tool used to build and maintain a site like this one.

When to use Claude, and when not to

Use Claude for

  • Writing anything that needs to sound human
  • Reading and summarizing long documents
  • Following complex, multi-step instructions
  • Drafting client-facing emails and scripts
  • Creating SOPs and training materials
  • Tasks where tone and nuance matter

Claude cannot

  • Access the internet or live market data
  • Send emails or take actions outside the chat
  • Verify legal requirements. Always cross-check
  • Give licensed real estate, legal, or financial advice
  • Remember previous conversations (unless Projects)
  • Guarantee factual accuracy. Verify critical details
Important

Claude is not a licensed professional. It is not a real estate agent, attorney, or accountant. Any output that touches legal, financial, or compliance topics must be reviewed by a qualified person before you use it with a client or in an official document.

Prompting Claude with the R.E.A.C.H. Framework

Claude responds to what you give it. The single biggest improvement you can make to any prompt is adding more context. Use R.E.A.C.H. as a checklist before you send.

Prompt Framework

Prompt with R.E.A.C.H.

A repeatable structure for every prompt you write. It works whether you're drafting an email or building a checklist.

R

Role

What role you're in and what task you're doing.

E

End goal

What you're actually trying to accomplish.

A

Audience

Who will read or use the output.

C

Context

Key details, numbers, or constraints.

H

How

Tone, length, and format you need back.

Understanding the context window

Every Claude conversation has a token limit: a ceiling on how much text it can hold at once. Tokens are roughly three-quarters of a word. The context window includes your messages, Claude's responses, and anything you paste in.

Module 02 ChatGPT by OpenAI
OpenAI · GPT Architecture

ChatGPT

Made by OpenAI — founded 2015, launched publicly November 2022

The most widely-used AI assistant in the world, with web browsing, image generation, and a massive ecosystem of integrations built on top of it.

What it is

ChatGPT is built on OpenAI's GPT (Generative Pre-trained Transformer) models. When it launched in November 2022, it became the fastest-growing consumer application in history, reaching 100 million users in two months. That reach matters: because so many people use it, an enormous ecosystem of tools, integrations, and custom-built assistants has been built on top of it.

The biggest practical difference from Claude is internet access. ChatGPT can search the web in real time, which means it can look up current mortgage rates, today's local market stats, a recent news article, or a competitor's current pricing: things Claude cannot do from training data alone.

What ChatGPT does best

Web browsing & live data

Search the internet in real time: current rates, recent news, competitor listings, today's market data.

Image generation (DALL-E)

Create property lifestyle images, social media graphics, banner art, and visual mockups from text descriptions.

Deep Research

Multi-step web research with cited sources: competitive analysis, neighborhood reports, vendor comparisons.

Huge ecosystem

Thousands of integrations: ChatGPT Ads, Zapier, Make, HubSpot, and hundreds of custom GPTs for specific workflows.

Advanced reasoning (o3)

The o3 model uses extended thinking for complex analysis, multi-step math, and nuanced decision-making.

Data analysis

Upload a spreadsheet and ask questions. ChatGPT runs the numbers, builds charts, and explains what it found.

ChatGPT's tools beyond the chat window

chat.openai.com is the interface most people picture, but OpenAI ships several tools built on the same models, each suited to a different kind of work.

Custom GPTs Saved configurations

A Custom GPT is a saved configuration of ChatGPT: fixed instructions, a specific tone, and optional reference files, packaged behind a single name so a team can reuse it without rebuilding the prompt from scratch every time.

Codex Engineering agent

Codex is OpenAI's coding agent: an autonomous engineer that reads a codebase, writes and edits code, runs tests, and opens changes for review, either from the command line or from inside ChatGPT. It fills the same role for OpenAI's ecosystem that Claude Code fills for Anthropic's.

Canvas Side-by-side editing

Canvas opens a separate editing pane next to the conversation for long documents or code. Instead of regenerating the whole reply to fix one paragraph, you edit directly inside Canvas and ask ChatGPT to revise only the part you highlight.

Agent Mode Operates a browser

Agent Mode lets ChatGPT operate a web browser on its own: clicking, filling forms, and navigating multi-step tasks online, while you watch and can step in at any point. It is OpenAI's answer to tasks that need actual clicks on a real website, not just a written answer.

Standout features for real estate work

Web Browsing

When you need current information, such as today's mortgage rates, a recent news article about a market, a competitor's current pricing, or live MLS context, ChatGPT is the right tool. Claude does not have internet access; ChatGPT does.

DALL-E Image Generation

Generate property lifestyle visuals, social graphics, and banner images from a text description. Describe the scene (a modern open-plan kitchen, a family in a new home, a neighborhood aerial) and get a production-quality image. Available on Plus and Pro plans.

Deep Research

Give ChatGPT a research question and it spends 5-15 minutes reading dozens of web sources, then delivers a structured report with citations. Best for competitive market analysis, neighborhood deep-dives, vendor comparisons, and any research that normally takes hours.

ChatGPT Ads

OpenAI runs an advertising platform at ads.openai.com that places ads alongside live ChatGPT conversations. Targeting uses context hints, plain-language descriptions of the person and moment, instead of keywords. This is covered in full in the AI Lab guide.

When to use ChatGPT, and when not to

Use ChatGPT for

  • Anything that requires current, real-time information
  • Generating images for social media or ads
  • Multi-source research reports with citations
  • Uploading spreadsheets for data analysis
  • Building a custom GPT for a repeated workflow
  • ChatGPT Ads campaigns and context hints

Where Claude is stronger

  • Very long documents (200K vs 128K token window)
  • Tasks requiring strict instruction-following
  • Writing that needs to sound more natural
  • Precise legal or contract document analysis
  • When you need Claude-specific features like Projects
Module 03 Manus, AI Agent
Autonomous Agent · Action Layer

Manus

Built for executing multi-step tasks across systems, files, and integrations

Not a chatbot. An agent. Manus takes a goal, plans the steps, uses a browser and real integrations, and produces a deliverable autonomously.

What it is

Claude and ChatGPT answer your questions. Manus completes your tasks. The distinction matters: Manus operates inside a virtual computer, can use a web browser, read and write files, connect to your actual tools (Gmail, Google Drive, HubSpot, Canva, Meta Ads), and deliver a finished output like a spreadsheet, report, slide deck, or SOP document.

For VOOV VAs, this is the tool for work that crosses multiple systems and has more than three steps. Instead of doing each step yourself and pasting results between tools, you describe the goal to Manus and it coordinates the steps. The critical operating principle: Manus can do the work, but the VA is responsible for the judgment. The tool collects, organizes, drafts, and automates. The VA verifies facts, brand fit, client permission, compliance, and final readiness.

When Manus is the right tool

Use Manus when

  • The task has more than three steps coordinating multiple tools
  • The output should be a deliverable: spreadsheet, report, deck, SOP
  • The work benefits from a browser, code, or file transformations
  • The task is repeatable enough to build a Skill or template
  • You need to cross Gmail, Drive, CRM, and Canva in one workflow

Manus is not the best tool for

  • Final visual brand production. Use Canva or Adobe
  • Permanent automations. Build those in Zapier, Make, or n8n
  • Legal, financial, or compliance conclusions. Requires human review
  • Sending, deleting, or posting publicly without explicit approval
  • Bulk CRM changes without a backup and human sign-off

The B.R.A.I.N. Prompting Framework

Manus responds to structure. Vague goals produce vague work. The MYFRND B.R.A.I.N. framework is a repeatable way to brief Manus, and any AI, before it executes a task. It prevents hallucinations, reduces brand risk, and makes outputs client-ready.

MYFRND B.R.A.I.N. Framework

How to brief Manus before any task

Fill in all five components before you ask Manus to do anything that involves client data, live systems, or deliverables.

B

Brand

Client name, market, tone, offer, audience, assets to use.

R

Role

Assign Manus the expert role needed. "You are a CRM auditor specializing in real estate."

A

Audience

Who the final output is for and what they need to decide or do.

I

Instructions

Exact steps, format, platforms, data sources, and output requirements.

N

Non-Negotiables

What Manus must not do. "Do not send, delete, publish, or update live records."

Core concepts: Projects, Skills, and Connectors

Projects

Keep each client organized. A Manus project holds the client B.R.A.I.N., brand assets, SOPs, recurring deliverables, connector rules, and approved Skills. Do not rely on scattered chat history for client-sensitive work.

Skills

Reusable, file-based operating manuals for Manus. A "Weekly Real Estate Team Report" Skill defines exact data fields, report structure, tone, QA checklist, and delivery format, so the work is consistent every time, regardless of which VA runs it.

Connectors

The bridge between Manus and external systems. Gmail, Google Drive, HubSpot, Canva, Meta Ads, Zapier, Make, and dozens more. Treat every connector like a key to a client's office: use only the minimum access needed, only for the approved task.

Browser Operator

Manus can operate a web browser in a logged-in session: useful for portal tasks, site audits, dashboard screenshots, and data exports from tools without a direct connector. Always run read-only first. For any irreversible action, require a screenshot, a confirmation summary, and explicit approval before Manus proceeds.

The Three-Gate QA System

Every Manus task should pass through three quality gates before a deliverable is sent to a client. Gate 1 happens before Manus starts. Gate 2 happens during execution. Gate 3 happens on the finished output.

Gate 1
Input QA

Confirm client, task owner, due date, source files, connector permissions, source of truth, and forbidden actions before Manus starts.

Gate 2
Execution QA

Check the plan, selected connectors, read-only status, source citations, and whether Manus is asking before risky actions.

Gate 3
Output QA

Check facts, names, dates, math, tone, formatting, links, compliance, privacy, and spelling before the deliverable leaves your hands.

Human Approval Required
  • Sending emails, texts, DMs, newsletters, or calendar invites
  • Posting, editing, or deleting on social media
  • Changing ad budgets, billing, or payment information
  • Merging, deleting, or bulk-updating CRM records
  • Publishing website changes or deploying to production
  • Any claim involving legal, tax, financial, or compliance judgment
